# Support

This page applies to every repository in the Augentic organisation that does
not carry a `SUPPORT.md` of its own.

## Questions and problems

- **A bug or a missing feature:** open an issue on the repository concerned.
  Say what you ran, what you expected, and what happened, with the version or
  commit; a minimal reproduction shortens everything that follows.
- **A question about using a project:** open an issue too, labelled as a
  question. The maintainers answer there so the next person can find it.
- **A security problem:** do not open an issue; follow [SECURITY.md](SECURITY.md).

Issues are answered on a best-effort basis by the maintainers named in each
repository's `GOVERNANCE.md`. There is no paid or guaranteed support.

## Before you ask

- Read the repository's `README.md` and, for a change you intend to make, its
  `CONTRIBUTING.md`.
- Search the repository's issues, open and closed, for the same problem.
- Check that the problem is still present on the latest release.

## Contributing a fix

Fixes are welcome as pull requests; the repository's `CONTRIBUTING.md`
describes the procedure, the gate (`make ci`), and the Developer's Certificate
of Origin every commit accepts.
